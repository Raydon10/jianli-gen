# jianli-gen

一个基于隐私脱敏的简历生成 Skill。

你可以先写一份脱敏简历，再把姓名、手机号、邮箱这类隐私信息单独保存。Skill 会结合这些内容，生成可预览、可导出的最终简历。

## 适合什么场景

- 想用一份简历内容，切换不同风格模板
- 不想把真实隐私信息直接写进简历正文
- 想让预览和导出保持一致

## 怎么使用

1. 先准备一份脱敏简历，写成你希望 Skill 参考的内容。
2. 再填写隐私信息，比如姓名、照片、手机、邮箱、公司。
3. 选择一个模板，作为最终简历的风格参考。
4. 让 Skill 生成简历。
5. 在网页里查看最新结果，满意后导出。

## 你会得到什么

- 一份由脱敏内容生成的完整简历
- 预览时可按模板风格查看效果
- 导出时和预览尽量保持一致

## 小提示

- 模板主要负责样式，不需要你手动改内容。
- 如果你更新了隐私信息，保存后再生成，效果会更准确。
- 如果当前内容还没准备好，可以先把简历正文补完整，再继续生成。
